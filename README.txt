Автономна версія лендингу.

Файли:
- index.html — сторінка
- styles.css — стилі
- script.js — контент карток та FAQ
- assets/ — локальні зображення

Завантажте весь вміст папки в корінь будь-якого статичного хостингу (Netlify, GitHub Pages, Hostinger, CyberFolks тощо).
Кнопки покупки ведуть на чинну сторінку Softbook.
Юридичні сторінки наразі залишені як зовнішні посилання на старий сайт Weblium; за потреби їх варто також перенести окремими HTML-файлами.


ДОДАНО ДВА ТАРИФИ
У файлі index.html знайдіть два входження PASTE_LINK_29_ZL_HERE і замініть їх на посилання для оплати тарифу 29 zł. Посилання тарифу 49 zł залишене без змін.


ДОДАНО ЗАКРІПЛЕНУ ПАНЕЛЬ ПОКУПКИ
У нижній частині екрана постійно відображаються дві кнопки:
- тариф 29 zł;
- тариф 49 zł з індивідуальним зідзвоном.
Панель адаптована для комп’ютерів і телефонів.
